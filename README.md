# 멀티뷰 모바일

휴대폰 브라우저로 PC의 **멀티뷰**에 접속해 화면을 보고 조작하는 웹 앱입니다.

- PC에 멀티뷰가 설치·실행되어 있어야 합니다 (PC 첫 화면의 ID·비밀번호로 접속).
- 연결 요청은 비밀번호로 암호화되어 ntfy.sh를 거치고, 화면·소리·입력은 WebRTC로 기기끼리 직접 주고받습니다.
- 비밀번호는 기기에 저장되지 않고, 꺼낼 수 없는 암호 키(WebCrypto)로만 보관됩니다.
- 휴대폰에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 조작
| 동작 | PC에서 |
|---|---|
| 탭 | 왼쪽 클릭 (두 번 탭 = 더블클릭) |
| 꾹 눌렀다 떼기 / 두 손가락 탭 | 오른쪽 클릭 |
| 꾹 누른 채 끌기 | 드래그 |
| 한 손가락 이동 | 마우스 이동 (확대 중이면 화면 이동) |
| 두 손가락 위아래 | 스크롤 |
| 두 손가락 벌리기 | 화면 확대 |
| ⌨ 버튼 | 휴대폰 키보드 + 특수키 (Esc, Ctrl, 한/영 …) |
